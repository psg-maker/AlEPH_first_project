# ALEPH_first_project
--
AI와 나의 판단

사용한 AI 도구: GPT-5.6 Sol, GPT-6.5 ASTRA
AI에게 맡긴 일: 자연어로 전달한 요구사항을 바탕으로 HTML · CSS · JavaScript 코드를 작성하고 수정하는 작업.
내가 직접 판단한 일: ‘박성근’이라는 사람의 발자취와 경험 · 가치관을 무엇으로 보여줄지 정하고, 내용의 순서와 공개 범위, 화면에서의 위치를 결정했습니다.
AI 결과를 그대로 두지 않고 수정한 일: 하단 중앙 부근에 있던 “결과가 좋지 않아도…” 문구를 오른쪽 끝으로 옮기도록 다시 요청했고, 수정된 위치를 직접 확인했습니다. 제출 확인
역할 구분: 코드는 GPT가 작성했고, 페이지에 담을 내용과 표현은 제가 자연어로 정해 전달하고 최종 결과를 판단했습니다.
